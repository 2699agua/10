技术学习记录 · 第一周

1. 学习常见搜索引擎搜索语法

学习 Google、Bing 的高级检索语法，用来让搜索定位更加清晰准确，缩小搜索范围。

  • ""：匹配完全包含该短语的结果
  • site:：限定在指定网站内搜索
  • -：排除指定词汇
  • filetype:：只搜索特定格式的文件
  • intitle: 关键词必须出现在网页标题
  • inurl: 关键词必须出现在网页URL网址中
  • after: / before: 限定时间范围
  • OR：或；AND：且
  • AROUND(x)：两个词语之间最多相隔 x 个词
  • Bing：contains: 查找网页里包含指向某种文件类型的超链接的页面

3. Markdown基础语法学习

掌握 Markdown 常用基础书写语法：

  • 标题：# 标题，#数量代表标题级别
  • 加粗：**文字**
  • 斜体：*文字*
  • 删除线：~~文字~~
  • 无序列表、有序数字列表
  • 链接 [文字](网址)、图片 ![说明](图片地址)
  • 引用块 > 文字
  • 行内代码 `代码`，代码块使用三个反引号 ``` 包裹
  • 分割线 ---，表格语法

4. 了解前端三件套

  • HTML：负责网页结构、内容，定义页面上有什么元素。
  • CSS：负责网页外观排版，控制页面的样式颜色。
  • JavaScript(JS)：负责网页交互行为，决定页面“能做什么、怎么响应”。

浏览器运行环境：浏览器负责解析HTML、CSS，执行JavaScript，最终渲染出网页。

API：前端页面通过API与后端进行对话交互；后端做数据逻辑与代码运行。

5. HTTP协议基础学习

5.1 GET 与 POST

  • GET：获取信息
  • POST：提交、提供数据信息

5.2 鉴权：校验身份信息

  • Cookie：存放在浏览器内，每次请求自动携带。
  • Session：重要信息存放在服务端；服务端压力大，占用内存。
  • JWT：用密钥完成验证；服务端压力小，适合前后端分离。

5.3 常见HTTP状态码含义

  • 1xx — 信息
  • 2xx — 请求成功（例：200）
  • 3xx — 重定向（例：302）
  • 4xx — 客户端错误（例：404）
  • 5xx — 服务器出现问题

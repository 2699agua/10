看看在哪 · 博客的美化

记录一次博客视觉升级，从配色到排版，让阅读体验更舒服。

这是我博客美化系列的第一篇，主要记录我如何调整网站的 配色方案 和 文章排版，让整体阅读体验更舒适。

为什么开始美化博客

最初的博客只是一个纯白背景加黑色文字的极简页面，虽然能用，但总觉得缺少一点"人味"。后来我意识到，博客不只是存放文字的地方，它也是我表达审美的一部分。

好的设计是隐形的，读者不会注意到它，但会感到舒服。

配色方案

我最终选择了深色为主、辅以柔和蓝紫色的配色。核心变量如下：

:root {
  --bg: #0f1115;
  --surface: #171a21;
  --accent: #7c9cff;
  --text-primary: #e8eaed;
  --text-secondary: #9aa3b2;
}

深色背景能减少长时间阅读的视觉疲劳，而 --accent 用于强调按钮、链接和关键元素，让页面有视觉焦点。

排版细节

排版上我做了几件事：

  • 正文最大宽度限制在 720px，避免一行太长
  • 行高设置为 1.8，中文阅读更透气
  • 段落之间留出足够间距，视觉上更清晰
  • 标题前加一条短竖线，形成视觉锚点

暗色 / 亮色切换

通过 CSS 变量 + localStorage，我实现了一键切换主题。核心逻辑是给 <html> 加一个 data-theme="light" 属性，然后在 CSS 里覆盖变量。

html[data-theme="light"] {
  --bg: #f7f8fa;
  --text-primary: #1a1d23;
  --accent: #4f6ef7;
}

小结

美化博客不是一蹴而就的事，它是一个不断调整的过程。重要的是先动起来，然后在阅读自己文章的过程中，慢慢发现哪里不舒服，再一点点改进。

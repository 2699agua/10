学习总结与进度记录

1. 学会常见的搜索引擎的搜索语法

掌握了利用高级搜索语法来定位更佳、清晰、准确的搜索结果，并用于控制搜索范围。

  • " "：返回完全包含这个短语的结果
  • site:：限定网站（注：Bing 冒号后不要加空格，site 最多支持 2 级域名）
  • -：排除词
  • filetype:：只搜索特定格式的文件
  • intitle:：关键词出现在网页标题中
  • inurl:：关键词出现在网页 URL 中
  • after: / before:：时间范围
  • OR：或；AND：且
  • AROUND(X)：两个词之间最多相隔 X 个词

补充：Bing 支持 intitle:、inbody:、NEAR:、NOT:、contains: 等语法。

4. 了解前端三件套

  • HTML：负责网页的结构与内容，决定页面上有什么。运行环境是浏览器，浏览器解析 HTML、CSS，执行 JavaScript，最终渲染页面。
  • CSS：负责网页的外观和排版，决定网页的颜值。
  • JavaScript (JS)：负责网页的行为和交互，决定页面“能做什么”。

API：前端渲染出来的页面，通过 API 进行对话交互，后端负责数据逻辑与代码运行方向。

5. Get & Post、鉴权与状态码

  • Get & Post：Get 用于获取信息，Post 用于提交/提供信息。
  • 鉴权：Cookie（存在浏览器中，每次请求自动带上）、Session（将重要信息存在服务器上，服务器再返回 ID 给客户端）、JWT（用密钥进行验证，服务器端无需存储，通过加密算法验证）。
  • 常见状态码：1xx 信息、2xx 成功（如 200）、3xx 重定向（如 301）、4xx 客户端错误（如 404）、5xx 服务器端问题（如 500）。
